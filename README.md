# Portfólio de desenvolvimento

Portfólio pessoal de desenvolvimento front-end e back-end, com projetos feitos
usando HTML, CSS e JavaScript.

## Projeto em destaque

### Passeandonafoto360® — redesign de site

Estudo de caso de modernização de um site que antes estava no Canva. O trabalho
preserva a identidade e as informações da marca e apresenta uma experiência
responsiva, com parallax, animações e galeria horizontal.

- **Antes:** [site original no Canva](https://passeandonafoto360.my.canva.site/)
- **Depois:** [site publicado na Vercel](https://passeandonafoto360.vercel.app/)
- **Versão deste portfólio:** [abrir projeto no GitHub Pages](https://cloudstrife-coder.github.io/projetos/passeandonafoto360/)
- **Código e estudo de caso:** [projetos/passeandonafoto360](./projetos/passeandonafoto360/)
- **Tecnologias:** HTML semântico, CSS3 e JavaScript nativo, sem frameworks.
